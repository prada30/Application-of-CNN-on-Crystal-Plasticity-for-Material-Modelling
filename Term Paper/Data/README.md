\# Dataset



This directory is used to store the extracted dataset required for training

and evaluating the CNN model.



The main dataset is:



`extracted\_data.h5`



The dataset is not included in this repository because of its large file size.



The expected local directory structure is:



Term Paper/

└── Data/

&#x20;   └── extracted\_data.h5



The dataset is generated/processed using the data extraction workflow provided

in this repository.
